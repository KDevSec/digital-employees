# 工作台（独立应用）

数字员工套件的本地管理端——**独立应用**，exe/CLI 安装，启动本地 Web 服务，浏览器访问。

## 形态

- **安装**：exe 安装包（Windows）或一行命令（macOS/Linux）
- **运行**：安装后启动本地 Web 服务，浏览器打开 `localhost:19820`
- **参照**：QoderWaker 的 UI 形态和交互模式（截图见 `../docs/references/QoderWaker/`）

## 六大模块（参照 QoderWaker UI）

| 模块 | 功能 |
|------|------|
| 我的员工 | 员工列表 + 创建向导 + 详情页（多 tab） |
| 我的群组 | 群组管理 + 绑定 workflow |
| workflow 编排 | SOP 可视化编辑器（Canvas/Script 双视图） |
| 任务看板 | List/Lanes 双视图 + Approval Workbench |
| 底座与环境管理 | 底座卡片 + 版本漂移检测 + 一键对齐 |
| 对话界面 | 与员工/群组直接对话 + 任务建议卡片 |

## 七大能力

- 编排引擎（R1 状态机 / R2 节点图 / R3 gate）
- 编排驱动（flow-driver / goal）
- 员工注册发现
- 工程记忆
- 合规监督（CQO）
- 本地观测（HUD）
- 多底座适配（四层正交）

## 与底座的关系

工作台**独立运行**，不嵌入任何底座。通过四层适配器（UPP）将员工包安装到各底座并监控运行状态。
