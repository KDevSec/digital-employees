# 个人信息安全安全合规检查规则

| 编号 | 类别 | 规则描述 |
|------|------|----------|
| PI-60 | 个人信息安全 | 实施数据最小化原则，只收集和处理业务必要的个人信息。 |
| PI-61 | 个人信息安全 | 对敏感个人信息进行加密存储，如身份证号、银行卡号等。 |
| PI-62 | 个人信息安全 | 提供隐私政策和用户同意机制，明确告知用户数据的收集、使用和共享方式。 |
| PI-63 | 个人信息安全 | 实现数据主体的权利，包括查询、更正、删除和导出个人数据的能力。 |
| PI-64 | 个人信息安全 | 对个人信息的访问进行严格的控制和审计，记录所有访问操作。 |
| PI-65 | 个人信息安全 | 不要在日志中记录完整的个人信息，只记录必要的操作信息并进行脱敏。 |
| PI-66 | 个人信息安全 | 数据跨境传输前进行合规评估，确保符合相关法规要求。 |
| PI-67 | 个人信息安全 | 对第三方数据处理者进行安全评估和合同约束，确保数据在第三方处的安全性。 |
| PI-68 | 个人信息安全 | 实施数据生命周期管理，包括数据分类、保留期限和安全删除。 |
