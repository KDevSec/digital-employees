# 错误处理和日志安全合规检查规则

| 编号 | 类别 | 规则描述 |
|------|------|----------|
| EL-87 | 错误处理和日志 | 对所有异常进行捕获和处理，防止应用程序崩溃或泄露敏感信息。 |
| EL-88 | 错误处理和日志 | 在生产环境中显示通用错误信息，不显示详细的堆栈跟踪或调试信息。 |
| EL-89 | 错误处理和日志 | 记录足够的安全事件日志，包括登录尝试、权限变更、数据访问等。 |
| EL-90 | 错误处理和日志 | 日志中不记录敏感信息，如密码、信用卡号、个人身份信息等。 |
| EL-91 | 错误处理和日志 | 对日志进行保护，防止未授权的访问、修改或删除。 |
| EL-92 | 错误处理和日志 | 日志记录包含足够的上下文信息，如时间戳、用户ID、IP地址、请求路径等。 |
| EL-93 | 错误处理和日志 | 定期审查日志，识别异常行为和潜在安全事件。 |
| EL-94 | 错误处理和日志 | 设置合理的日志保留策略，符合法规要求并便于事件响应。 |
| EL-95 | 错误处理和日志 | 错误处理机制不应导致性能问题或资源耗尽。 |
