# 数据库安全安全合规检查规则

| 编号 | 类别 | 规则描述 |
|------|------|----------|
| DB-81 | 数据库安全 | 使用输入验证和输出编码，并确保处理了元字符。如果失败，则不执行数据库命令。确保变量是强类型的。 |
| DB-82 | 数据库安全 | 当应用程序访问数据库时，应使用尽可能最低的权限。 |
| DB-83 | 数据库安全 | 连接字符串不应当在应用程序中硬编码。连接字符串应当存储在一个可信服务器的独立配置文件中，并且应当被加密。 |
| DB-84 | 数据库安全 | 使用存储过程以实现抽象访问数据，并允许对数据库中表的删除权限。 |
| DB-85 | 数据库安全 | 删除或者修改所有默认的数据库管理员密码。使用强密码、强短语，或者使用多因子身份验证。 |
| DB-86 | 数据库安全 | 关闭所有不必要的数据库功能（比如：不必要的存储过程或服务、应用程序包、仅最小化安装需要的功能和选项（表面范围缩减）。 |
| DB-87 | 数据库安全 | 删除厂商提供的不必要的默认信息（比如：数据库模式示例）。 |
| DB-88 | 数据库安全 | 禁用任何不支持业务需求的默认账户。 |
| DB-89 | 数据库安全 | 应用程序应当以不同的凭证为每个信任的角色（比如：用户、只读用户、访问用户、管理员）连接数据库。 |
