# 系统配置安全合规检查规则

| 编号 | 类别 | 规则描述 |
|------|------|----------|
| SC-78 | 系统配置 | 移除或禁用不需要的默认账户、默认密码和示例应用程序。 |
| SC-79 | 系统配置 | 关闭不必要的服务和端口，只开放业务必需的端口。 |
| SC-80 | 系统配置 | 配置文件和配置数据库存储在安全位置，限制对配置的访问权限。 |
| SC-81 | 系统配置 | 敏感配置信息（如密码、密钥）使用加密存储，不要明文写入配置文件。 |
| SC-82 | 系统配置 | 生产环境禁用调试模式和详细错误信息，防止信息泄露。 |
| SC-83 | 系统配置 | 实施安全头配置，如CSP、X-Frame-Options、X-XSS-Protection、HSTS等。 |
| SC-84 | 系统配置 | 定期更新操作系统、应用服务器、数据库和第三方组件，修复已知漏洞。 |
| SC-85 | 系统配置 | 配置日志记录，包括安全事件日志、访问日志和错误日志。 |
| SC-86 | 系统配置 | 实施备份策略，包括定期备份、离线存储和定期恢复测试。 |
