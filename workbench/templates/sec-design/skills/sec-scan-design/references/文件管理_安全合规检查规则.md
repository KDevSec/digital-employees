# 文件管理安全合规检查规则

| 编号 | 类别 | 规则描述 |
|------|------|----------|
| FM-69 | 文件管理 | 将上传的文件存储在Web根目录之外，防止直接访问执行。 |
| FM-70 | 文件管理 | 验证上传文件的类型，不依赖文件扩展名，而使用文件内容检测。 |
| FM-71 | 文件管理 | 限制上传文件的大小，防止大文件导致的拒绝服务攻击。 |
| FM-72 | 文件管理 | 对上传的文件进行病毒扫描，特别是来自不受信任来源的文件。 |
| FM-73 | 文件管理 | 不要在文件路径中使用用户提供的输入，防止路径遍历攻击。 |
| FM-74 | 文件管理 | 设置合理的文件权限，应用程序只能访问必要的文件和目录。 |
| FM-75 | 文件管理 | 对敏感文件进行加密存储，确保即使文件泄露也无法读取内容。 |
| FM-76 | 文件管理 | 记录文件访问和操作日志，包括上传、下载、删除等操作。 |
| FM-77 | 文件管理 | 不要在错误信息中泄露文件路径和系统信息。 |
