# 会话管理安全合规检查规则

| 编号 | 类别 | 规则描述 |
|------|------|----------|
| SM-42 | 会话管理 | 会话标识符（Session ID）必须使用足够长度的随机值，使用CSPRNG生成。 |
| SM-43 | 会话管理 | 会话ID通过HTTP Cookie传输，设置Secure和HttpOnly属性。 |
| SM-44 | 会话管理 | 设置合理的会话超时时间，包括空闲超时和绝对超时。 |
| SM-45 | 会话管理 | 在用户登录后重新生成会话ID，防止会话固定攻击。 |
| SM-46 | 会话管理 | 提供用户注销功能，并在注销后使服务器端会话失效。 |
| SM-47 | 会话管理 | 不要在URL中传输会话ID，防止会话ID被记录在日志和浏览器历史中。 |
| SM-48 | 会话管理 | 设置SameSite Cookie属性，防止跨站请求伪造（CSRF）。 |
| SM-49 | 会话管理 | 限制每个用户的并发会话数量，防止会话劫持和账户共享。 |
| SM-50 | 会话管理 | 将敏感操作的会话进行二次验证，比如重新输入密码或使用多因素认证。 |
