# 加密规范安全合规检查规则

| 编号 | 类别 | 规则描述 |
|------|------|----------|
| CR-30 | 加密规范 | 使用业界推荐的算法和加密参数。 |
| CR-31 | 加密规范 | 建立密钥管理过程，包括密钥的生成、分发、存储、轮换和销毁。 |
| CR-32 | 加密规范 | 密钥存储在安全的位置，如硬件安全模块（HSM）或加密的密钥管理系统。 |
| CR-33 | 加密规范 | 使用TLS/SSL进行数据传输加密，确保传输中的数据机密性和完整性。 |
| CR-34 | 加密规范 | 使用强随机数生成器（CSPRNG）生成加密密钥和随机值。 |
| CR-35 | 加密规范 | 密码存储使用加盐哈希算法（如bcrypt、Argon2或scrypt），绝不以明文存储密码。 |
