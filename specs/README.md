# Feature specifications

本目录是数字员工套件 2.0 的 Spec Coding 工作区。

每个功能使用递增编号和短名称建目录，例如 `001-employee-installation/`，目录内仅包含：

- `spec.md`：问题、目标、用户故事、验收场景和约束
- `decisions.md`：该功能的 ADR-001
- `plan.md`：技术方案、接口、测试、发布与风险
- `tasks.md`：按用户故事组织的可执行任务和验证清单

使用项目级 `speckit` 技能创建和维护这些产物；实现时结合 Superpowers 的 TDD、系统化调试和完成前验证流程。
