## 1. 背景与目标

| 维度 | 现状（V0.1） | 目标 |
|---|---|---|
| 制品形态 | 三 exe 绿色兼容（devzero.exe / devzero-daemon.exe / devzero-tray.exe） | 不变（绿色兼容性保留） |
| 正式分发路径 | install.ps1 安装脚本（落盘 + 计划任务 + 快捷方式 + 起托盘） | **Inno Setup 安装包 setup.exe**，install.ps1 退役 |
| 卸载 | 手工说明（stop → 删目录 → 删任务） | 「设置 → 应用」原生卸载入口 |
| 升级（U-03） | 手动重跑脚本 | 双击新 setup.exe 覆盖升级，中断窗口 ≤ 20s（原 15s，用户裁决 C 2026-08-25，§5.1） |

三制品分工不变：服务（devzero.exe，console 子系统——CLI 面需要控制台输出）+ 守护变体（devzero-daemon.exe，GUI 子系统防黑窗）+ 托盘壳（devzero-tray.exe，含单实例 + 唤醒重定向）。

**品牌重命名注记**（用户裁决 2026-08-25，标识符级 workbench→devzero；安装器域 Task 1 落地）：三制品 exe 名、安装目录 `Programs\devzero`、计划任务名 `DevZeroDaemon`、Run 键 `DevZeroTray`、profile 目录 `~/.devzero`、图标 `devzero.ico`、显示名 DevZero 用新名；工程目录 `workbench/workbench-installer/`、iss 文件名 `workbench.iss`、环境变量 `WORKBENCH_HOME` / `WORKBENCH_SIGN_CERT`、协议端点 workbench-* 保留旧名（重命名裁决范围外）。本文以下按新名表述。

## 2. 裁决记录（2026-08-25，用户逐项裁决）

| # | 议题 | 裁决 | 要点 |
|---|---|---|---|
| 1 | 安装路径边界 | **C：setup.exe 单一路径 + 静默参数** | install.ps1 退役删除；开发者用 `/VERYSILENT` 同一路径，不维护两套落盘逻辑 |

| 5 | 安装器选型 | **Inno Setup** | per-user / 快捷方式 / 覆盖升级 / 静默安装四个核心诉求原生声明式支持；唯一妥协 = 卸载数据询问降级为 MsgBox（NSIS 为此一个界面手搭全套不值；WiX 对单用户桌面工具 YAGNI；MSIX 强制签名与裁决 4 冲突，排除） |
| 6 | 安装目录 | **固定不可改**（`DisableDirPage=yes`） | `%LOCALAPPDATA%\Programs\devzero`（品牌重命名 2026-08-25 落定；原 workbench 路径不再对齐——install.ps1 未随改名且即将退役（§7），本机旧标识已清）；计划任务/Run 键/快捷方式引用的绝对路径永远不变，升级 = 原地换文件 |
| 7 | 图标 | **临时占位** | `workbench-installer/assets/devzero.ico`（Task 1 品牌重命名自然延伸：workbench.ico 已更名）；用户后续生成正式图标同路径覆盖，iss 零改动——「同路径替换」语义不变 |

**裁决 3 备注（执行期修订：Task 4 判别实验 + 用户裁决 C 2026-08-25）**：中断窗口预算 5–8s 估算失准——实测 11–18s，主因 lzma2/max 解压落盘 ~7s（Inno 日志时间戳实锤：ssPostInstall 任务注册仅 ~0.4s；机器负载方差另贡献波动）。裁决 C 双保险：① Compression 降档 lzma2/max → lzma2/fast（直接砍解压大头）；② 验收硬线 15s → 20s（机器忙时 18s 曾翻 15s 线）。代价 = 安装包体积 56 → 71.7MB——solid 压缩下双变体 exe（devzero.exe / devzero-daemon.exe）共享压缩数据，体积增幅远小于预估；下载是一次性成本，每次升级的中断是反复成本。降档后实测 13–17s。

**端口边界澄清**：安装阶段的端口风险由装前优雅 stop 消除（服务退出即释放 19980）；装后启动若遇**第三方**占用 19980，属服务运行期端口冲突语义（§7.4 裁决：退出码 78 + 诊断），不在安装器责任边界。

**发布卡口豁免**：「VersionInfo 不泄露构建工具」继续约束三制品；setup.exe 携带 Inno 编译器签名，豁免该卡口（安装器是分发载体非业务制品）。

## 4. 构建链（build-installer.sh）

1. **前置检查**：三制品已在 `workbench-service/dist/`（**不代跑上游构建**——与 build-tray.sh 缺制品时代跑 service 的策略相反：安装包要求三制品齐备的确定性输入，缺哪个提示操作者跑哪个；Task 1 review 修正同源注释漂移）；`iscc.exe` 探测：`ISCC_PATH` 显式覆盖 > PATH > 默认安装路径（winget 装机不进 PATH），全无才报清晰错误并退出（Task 6 review Minor 1：原表述优先级倒置）
2. **版本注入**：读 `workbench-service/package.json` 的 `version` → `iscc -DMyAppVersion=<version>` —— 安装包版本 = 服务主版本线；壳版本独立线（W-12）不进安装包版本。参数用 `-D` 前缀：git-bash MSYS 把 `/D` 形态当 POSIX 路径转换，ISCC 报 "more than one script filename"（Task 1 判别实验实锤）
3. **编译产物**：`workbench-service/dist/devzero-setup-<version>-x64.exe` + 同名 `.sha256` 文件（平台上传 U-02 校验直接消费）。iss 内相对路径按 **iss 所在目录**解析：OutputDir / Source 用 `..\workbench-service\dist` 单层上跳（计划稿 `..\..\` 两层上跳到仓库根找不到制品，不可编译——Task 1 判别实验实锤）
4. **signtool 挂点**：`WORKBENCH_SIGN_CERT` 存在才调 signtool，否则跳过（裁决 4 预留位）。参数 `-fd/-f/-p` 前缀——与 iscc `/D` 同源 MSYS 转换缺陷（Task 1 spec review 抓出）

工具链依赖：构建机一次性安装 Inno Setup（不进 git）；与现状无 CI、本地 bash 构建形态一致。

**中文向导（isl 来源，Task 1 实然）**：设计原拟「Inno 6 自带 / istrans 下载」——实然：官方安装包（6.7.3）的 `Languages/` 不含简中（判别实验核实：本机 Languages/ 目录无 ChineseSimplified.isl）、istrans 旧路径 404（社区翻译已升官方，改随源码仓库分发）。实作 = 从 jrsoftware 官方源码仓库（issrc main）下载 `ChineseSimplified.isl` 随仓分发（`assets/ChineseSimplified.isl`，sha256 与官方逐字节一致）；InfoBeforeFile「安装前须知」页承载 SmartScreen 预告 + sha256 核对说明。

**平台对接（U-01/U-02/U-03）**：运营手动上传 admin 端点（os=windows、arch=x64、version、sha256、signature_status=UNVERIFIED）——V0.1 不做上传自动化；工作台 UI 检查更新 → 引导下载 → 校验 sha256 → 用户手动执行，全程不静默替换（既有裁决）。

## 5. 三大行为语义

### 5.1 安装（首装 + 覆盖升级同一路径）

| 步骤 | 行为 | 说明 |
|---|---|---|
| 1. 装前清理 | `[Code] PrepareToInstall`：`devzero.exe stop`（失败不中止——服务可能本就没跑 / 首装尚无 exe）→ **三进程 taskkill 硬杀兜底**（托盘/服务/守护，解文件锁） | install.ps1 重装健壮性段（2c7f3fb）翻译；三进程全杀自 Task 3 起，卸载前置清理（§5.3）Task 5 镜像同款模式 |
| 2. 落盘 | 三制品 → `{localappdata}\Programs\devzero` | 固定路径（裁决 6） |
| 3. 系统集成 | 计划任务 **Force 重建**（PowerShell 单次 exec：每分钟触发器 + 四反直觉默认值覆写 + `__daemon` 变体，逐字翻译 install.ps1；重建不跳过——新版任务设置演进不被旧装机残留拖住）→ 清 user-stopped 哨兵；快捷方式（[Icons]，指向托盘 exe）由 Inno 在 ssPostInstall 之前独立创建（不在此链） | 任务名 `DevZeroDaemon`；哨兵清除 = 安装意图要运行，路径 **WORKBENCH_HOME 感知**（GetEnv 非空用之，否则 `%USERPROFILE%\.devzero`——与服务 profile 解析同语义，Task 3 裁决调整） |
| 4. 立即恢复 | `ssPostInstall` 后台起托盘 → 启动即活拉服务（裁决 3：与用户解耦） | 中断窗口结束点 |
| 5. 完成页 | 复选框「打开工作台页面」**默认不勾**（`unchecked`）；仅交互模式出现（`skipifsilent` + `WizardNotSilent` 双保险），**静默模式原生跳过——无人值守不开浏览器**（执行期设计修订，Task 1）。勾选后经托盘 exe 而非 URL 打开：托盘 openWorkbench 自带 healthz 等待 + 单实例唤醒语义 | 仅控制浏览器，不控制服务 |

**中断窗口**（裁决 3）：原预算 stop(≤2s) + 落盘(<1s) + 集成(1–3s) + 服务冷启动(1–2s) ≈ 5–8s——实测失准（11–18s，主因 lzma2/max 解压落盘 ~7s，Task 4 判别实验；机器负载方差另贡献波动）。用户裁决 C 后（lzma2/fast + 硬线 20s，见 §2 裁决 3 备注）实测 13–17s；窗口与用户手速无关。

**ssPostInstall 顺序与留痕**（Task 3 验证）：ssPostInstall 内三步顺序 = 任务重建 → 清哨兵 → 起托盘；任务注册失败双层留痕（Exec 返回 False / PowerShell 退出码非 0）显式 Log 进 `/LOG` 日志——Exec 不写 Inno 日志，不留痕则装机现场零感知（Task 3 review Minor 1 修复）。

### 5.2 升级

用户从平台下载新 setup.exe → 双击 → 5.1 全流程（步骤 1 自动停旧版、步骤 4 自动恢复）。安装器不感知「升级 vs 首装」。

### 5.3 卸载

1. 前置清理：`devzero.exe stop`（落哨兵，守护不复活；退出码非 0 留痕——「文件删除受阻」第一嫌疑）→ **三进程硬杀兜底**（devzero-tray / devzero / devzero-daemon——镜像 PrepareToInstall 模式：封文件锁与 daemon 复活窗口；Task 5 实修，计划原只杀托盘）→ 计划任务先禁用（掐每分钟触发器在途窗口）再删（`schtasks /Delete /TN DevZeroDaemon /F`）→ 删 HKCU Run 键 `DevZeroTray`（对齐壳侧 W-16 双侧注销）
2. 数据询问（裁决 2）：交互模式 MsgBox「是否同时删除用户数据（登录态 / 密钥 / 工程记忆）？」默认否；静默卸载零弹窗走默认保留
3. 显式清除：命令行 `/DELETEDATA=1` = 连数据目录一起删。**数据目录解析**（DataDir）与制品 profile 同语义（probe.go ProfileDir）：`WORKBENCH_HOME` 非空用之，否则 `%USERPROFILE%\.devzero`——S4 冒烟安全性依赖（删隔离目录而非真实 profile；Task 5）。**参数扫描区间** `ParamStr(1)..ParamCount`（Inno 文档：ParamStr(0) 是 exe 路径——计划稿 `0..ParamCount-1` 漏扫末位参数，`/DELETEDATA=1` 恰在末位时静默失效；Task 5 实修）

## 6. 测试与验收

**冒烟 installer-smoke.sh**（真 setup.exe 全链，场景化风格对齐 tray-smoke.sh）：

| 场景 | 动作 | 断言 |
|---|---|---|
| S1 静默首装 | `setup /VERYSILENT` | 三制品落盘、计划任务存在、快捷方式存在、healthz 就绪、托盘进程在、Inno 日志生成且无 error |
| S2 覆盖升级 | 旧版在跑 → 再执行 setup | 无文件锁失败、文件已更新（**文件 ID 变化**——mtime 断言不可用，见下）、服务与托盘恢复；**中断窗口（healthz 不可达 → 恢复）≤ 20s**（裁决 3 硬断言；硬线 15→20s = 用户裁决 C 2026-08-25） |
| S3 卸载·保留数据 | 静默卸载 | 目录删、任务删、Run 键删、**数据目录完整保留**（数据目录按 WORKBENCH_HOME 感知解析，§5.3——冒烟断言的是隔离目录而非真实 profile） |
| S4 卸载·清除数据 | 卸载 `/DELETEDATA=1` | 同上 + 数据目录已删（DataDir 与制品 ProfileDir 同语义是此安全性的根，§5.3） |

**S2 断言与测量语义（Task 4 判别实验修订）**：
- Inno 覆盖安装**保留源文件时间戳**（Inno 日志 "Time stamp of our file" == "Time stamp of existing file"）——「文件已更新」断言用文件 ID（`stat %i`：Inno 经临时文件 + 重命名落盘，每次覆盖必变）而非 mtime
- 窗口测量 = healthz 轮询：down **锁定首个不可达时刻**（不可达期间不覆盖——计划稿逐次覆盖会把任意长窗口测成 ≈1 个轮询间隔的假 PASS，且可产生负值窗口）、up = down 后首个可达；服务恢复可晚于 setup 退出 ~2s（托盘→服务启动链），测量不绑 setup 存活期

**环境事实（git-bash 调 setup / unins000 三坑，2026-08-25 判别实验实测）**：
1. **MSYS 参数转换**：`/VERYSILENT`、`/LOG=`、`/DELETEDATA=1` 等单斜杠参数被 git-bash 当 POSIX 路径改写（与 iscc `/D` 同源坑）——调用须 `MSYS2_ARG_CONV_EXCL="*"` 让参数原样直达
2. **`/LOG=` 须 Windows 路径**（`cygpath -w`）——setup.exe 是 Windows 程序，解析不了 MSYS `/tmp` 形态路径
3. **unins000 异步自复制**：unins000.exe 自复制到临时目录异步执行——返回 ≠ 完成（实测返回时目录仍在删），断言前必须轮询断言物（任务 / Run 键 / 安装目录 / 快捷方式）消失

人眼验收项（GUI 不可脚本化）：中文向导页、SmartScreen 弹窗实测、完成页复选框、卸载 MsgBox。

## 8. 风险与缓解

| 风险 | 缓解 |
|---|---|
| 构建机需装 Inno Setup | 一次性安装不进 git；iscc 缺失时 build 脚本报清晰错误 |

| 卸载 MsgBox 体验不够优雅 | 已知妥协（裁决 5 接受）；NSIS 换血不划算，留 V0.2+ 若有强诉求再评估 |

## 9. 平台边界（用户问询 2026-08-25：是否牵连其他 OS 重新设计）

本设计 = **Windows 分发层 + 系统集成层**的设计，不牵连其他 OS：

- 服务本体（服务/CLI/编排/记忆）跨平台、托盘壳业务内核（状态机/契约/菜单模型）平台无关——均零触碰
- 平台差异被压缩在「分发 + 系统集成」层：Inno/per-user 免 UAC/计划任务/HKCU Run 全是 Windows 专属机制
- 既有裁决：D-h（Linux 无托盘壳）、darwin 托盘变体归 0.2
- 将来扩 OS = 增量新增「分发层设计 B（Linux：tar.gz + systemd user unit + .desktop，无 GUI 层反而更简）/ C（macOS：.app bundle + launchd + dmg）」，本设计不被推翻

## 10. 明确不做（YAGNI）

- 上传平台自动化（运营手动上传）
- 热替换/差量升级（D-l：无 bootstrapper）
- 代码签名（独立花钱决策，后续版本裁决）
- MSIX / 组策略部署（无此场景）
- 安装目录可选（裁决 6 固定）
- Linux/macOS 分发（§9：增量设计，非本设计范围）
