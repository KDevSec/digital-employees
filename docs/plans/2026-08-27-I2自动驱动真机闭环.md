# I2 自动驱动真机闭环 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Driver 装配 main.ts + RealLauncher（claude-code 先行）后，发起「五阶段快速交付」流程可全程无人干预自动推进到交付（含可配置人工评审门禁）。

**Architecture:** 消费 L2 `buildLaunchSpec`（LaunchSpec 纯构造值）只做 spawn+生命周期；prompt 走 stdin 规避 Windows 多行截断；`human_gate` 逐节点布尔 + 发起表单开关→选表映射。组件全部就绪，本计划主要是装配、新 RealLauncher、simple-flow 表、前置小改。

**Tech Stack:** TypeScript + Bun + vitest + zod + yaml

**Spec:** `docs/design/详细设计/I2自动驱动真机闭环详细设计-v0.1.md`（v1.2 定案）

## Global Constraints

- 零假数据红线：MockLauncher 不上产线，仅测试替身（D-053）
- TDD 红绿循环：每任务先写失败测试→红→实现→绿
- claude-code 版本断言：Windows 分档 2.1.226（P0a，M2 实测基线）
- prompt 通道：stdin 是双底座唯一共同可靠中转（M2 实锤）
- permission 必须显式传（CC 不传 -p 无写工具）
- 认证：本机 env token（ANTHROPIC_AUTH_TOKEN+BASE_URL），spawn 继承 service 环境
- 组件目录：`workbench-service/src/engine/`（Driver/SpawnRunner/Launcher）
- 类型契约：`LaunchInput{deployment,workdir,prompt,permission?,model?,effort?}` → `LaunchSpec{command,args,env,cwd,promptFile?}`（adapters/contract.ts）
