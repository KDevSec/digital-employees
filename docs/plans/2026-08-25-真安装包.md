# 真安装包（Inno Setup）实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 数字员工工作台从 install.ps1 脚本安装升级为 Inno Setup 真安装包（setup.exe），覆盖安装/升级/卸载全语义，install.ps1 退役。

**Architecture:** 新工程 `workbench/workbench-installer/`（workbench.iss + build-installer.sh + installer-smoke.sh），安装语义逐字翻译 install.ps1（装前清理/固定路径落盘/计划任务 Force 重建/哨兵清除/快捷方式），服务恢复与用户解耦（ssPostInstall 立即起），卸载带数据去留询问。设计文档：`docs/plans/2026-08-25-真安装包-design.md`（七项裁决见 §2）。

**Tech Stack:** Inno Setup 6.x（iscc.exe 命令行编译）、bash 构建脚本（git-bash，风格对齐 `workbench/workbench-tray/scripts/build-tray.sh`）、PowerShell（计划任务注册）。

**TDD 形态注记:** 安装器是声明式脚本无可单测逻辑，红绿循环映射为「冒烟断言先行（FAIL）→ iss 实现（PASS）」。测试面全在 `installer-smoke.sh`。

**执行注记:** 按项目惯例 main 直干（不开 worktree）。构建机需先装 Inno Setup（Task 0）。

## 背景速览（给零上下文执行者）

- 三制品：`workbench/workbench-service/dist/` 下 `workbench.exe`（服务/CLI）、`workbench-daemon.exe`（GUI 子系统守护变体）、`workbench-tray.exe`（托盘壳，含单实例+唤醒重定向）
- 服务端口 19980，healthz = `http://127.0.0.1:19980/healthz`；profile 目录解析语义：env `WORKBENCH_HOME` > `~/.workbench`（安装器卸载数据删除必须尊重同一语义——冒烟隔离安全性依赖它）
- 计划任务 `WorkbenchDaemon`（每分钟触发器 + `__daemon` 参数 + 四反直觉默认值覆写）——现逻辑在 `workbench/workbench-service/scripts/install.ps1:31-43`，本计划逐字翻译后退役该脚本
- 托盘 HKCU Run 键名 `WorkbenchTray`（`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`）
- 冒烟脚本环境事实（沿 tray-smoke.sh 教训）：git-bash 下 taskkill 用 `//F //IM` 双斜杠防 MSYS 路径转换；`WORKBENCH_NO_BROWSER=1` 抑制开浏览器；GUI exe 用 `(exe &)` 子壳后台形态

## 执行期设计修订（1 处，相对设计文档 §5.1 步骤 5）

**静默安装不开浏览器**（Inno 原生行为：`/VERYSILENT` 下 postinstall 条目跳过）。理由：静默 = 无人值守语义（开发者自装/冒烟），弹浏览器反而打扰；交互安装复选框默认勾、经托盘 openWorkbench 链路（自带 healthz 等待）开浏览器。执行时同步修订设计文档 §5.1 该行 + §2 裁决 3 备注。

**Step 3: 写 build-installer.sh**

```bash
#!/usr/bin/env bash
# 安装包构建（设计 §4 构建链）：
#   1. 前置检查：三制品已在 workbench-service/dist（不代跑上游构建，对齐 build-tray.sh 形态）
#   2. 版本注入：读 workbench-service/package.json version → iscc /D（安装包版本 = 服务主版本线）
#   3. iscc 编译 → dist/workbench-setup-<version>-x64.exe + 同名 .sha256（平台上传 U-02 直接消费）
#   4. signtool 挂点（裁决 4 预留位）：WORKBENCH_SIGN_CERT 存在才签名，否则跳过
set -euo pipefail

cd "$(dirname "$0")/.." # workbench/workbench-installer

DIST="../workbench-service/dist"
for f in workbench.exe workbench-daemon.exe workbench-tray.exe; do
  [ -f "$DIST/$f" ] || { echo "[build-installer] $DIST/$f 缺失——先跑 service/build.sh 与 tray/build-tray.sh"; exit 1; }
done

# iscc 探测：PATH > 默认安装路径（winget 装机不自动进 PATH）
ISCC="${ISCC_PATH:-}"
if [ -z "$ISCC" ]; then
  for c in iscc "/c/Program Files (x86)/Inno Setup 6/ISCC.exe" "/c/Program Files/Inno Setup 6/ISCC.exe"; do
    if command -v "$c" >/dev/null 2>&1; then ISCC="$c"; break; fi
  done
fi
[ -n "$ISCC" ] || { echo "[build-installer] iscc.exe 未找到——先装 Inno Setup 6（winget install JRSoftware.InnoSetup）或设 ISCC_PATH"; exit 1; }

# 版本注入（设计 §4：安装包版本 = 服务主版本线；壳版本独立线 W-12 不进）
VERSION="$(sed -n 's/.*"version": *"\([^"]*\)".*/\1/p' ../workbench-service/package.json | head -1)"
[ -n "$VERSION" ] || { echo "[build-installer] package.json version 读取失败"; exit 1; }

OUT="$DIST/workbench-setup-$VERSION-x64.exe"
"$ISCC" /DMyAppVersion="$VERSION" workbench.iss
SIZE="$(stat -c%s "$OUT")"
echo "[build-installer] built: $OUT ($SIZE bytes)"

# sha256 产物（U-02 平台上传直接消费）
sha256sum "$OUT" | awk '{print $1}' > "$OUT.sha256"
echo "[build-installer] sha256: $(cat "$OUT.sha256")"

# signtool 挂点（裁决 4：无证书零开销跳过）
if [ -n "${WORKBENCH_SIGN_CERT:-}" ]; then
  signtool sign /fd SHA256 /f "$WORKBENCH_SIGN_CERT" ${WORKBENCH_SIGN_P:+/p "$WORKBENCH_SIGN_P"} "$OUT" \
    && echo "[build-installer] 已签名" || echo "[build-installer] 签名失败（继续，signature_status 报 UNVERIFIED）"
else
  echo "[build-installer] 未设 WORKBENCH_SIGN_CERT——跳过签名（signature_status=UNVERIFIED）"
fi
```

**Step 1: 写冒烟脚本骨架（含全部防护与 S1 断言）**

```bash
#!/usr/bin/env bash
# 安装包冒烟（设计 §6）——真 setup.exe 全链真机验证：
#   S1 静默首装 / S2 覆盖升级（中断窗口 ≤15s 硬断言）/ S3 卸载保留数据 / S4 卸载清除数据
#
# 环境事实（沿 tray-smoke.sh 教训 + 安装器特有）：
#   - 安装器固定路径真实落盘（LOCALAPPDATA\Programs\workbench）——不可 mktemp 隔离，
#     前置检查「已装即中止」保干净前提；卸载才清场
#   - WORKBENCH_HOME 隔离服务/托盘 profile（安装器卸载数据删除尊重同一变量——S3/S4 安全性依赖）
#   - 计划任务 WorkbenchDaemon 必须全程 DISABLE：daemon 经任务计划触发无环境继承，
#     会用真实 ~/.workbench 抢 19980 端口干扰断言
#   - Run 键真实写注册表（托盘 applyAutostart）——备份恢复原值，不留痕
#   - WORKBENCH_NO_BROWSER=1 抑制开真浏览器；Inno /LOG 留安装日志供断言
set -euo pipefail

cd "$(dirname "$0")/../.." # workbench/workbench-installer
cd ../workbench-service     # 借 service 目录锚定 dist

SMOKE_LOG="../workbench-installer/scripts/installer-smoke.log"
: > "$SMOKE_LOG"
exec > >(tee -a "$SMOKE_LOG") 2>&1

BASE="http://127.0.0.1:19980"
RUN_KEY='HKCU\Software\Microsoft\Windows\CurrentVersion\Run'
RUN_KEY_NAME="WorkbenchTray"
TASK_NAME="WorkbenchDaemon"
INSTALL_DIR="$(cygpath -u "$LOCALAPPDATA")/Programs/workbench"
SETUP_EXE="$PWD/dist/workbench-setup-$(sed -n 's/.*"version": *"\([^"]*\)".*/\1/p' package.json | head -1)-x64.exe"
START_MENU_LNK="$(cygpath -u "$APPDATA")/Microsoft/Windows/Start Menu/Programs/数字员工工作台.lnk"

export WORKBENCH_HOME="$(mktemp -d)"
export WORKBENCH_NO_BROWSER=1

# ---- 前置防护 ----
[ -f "$SETUP_EXE" ] || { echo "ABORT: $SETUP_EXE 不存在——先跑 build-installer.sh"; exit 1; }
[ -d "$INSTALL_DIR" ] && { echo "ABORT: $INSTALL_DIR 已存在（已安装？）——先卸载再跑冒烟"; exit 1; }
for proc in workbench.exe workbench-daemon.exe workbench-tray.exe; do
  tasklist //FI "IMAGENAME eq $proc" 2>/dev/null | grep -i "$proc" >/dev/null && {
    echo "ABORT: 已有 $proc 在跑——请先关闭（冒烟会真实装/卸载同名安装）"; exit 1; }
done
PREV_RUN_VALUE="$(reg query "$RUN_KEY" //v "$RUN_KEY_NAME" 2>/dev/null | sed -n 's/.*REG_SZ[[:space:]]*//p' || true)"

cleanup() {
  taskkill //F //IM workbench-tray.exe >/dev/null 2>&1 || true
  taskkill //F //IM workbench.exe >/dev/null 2>&1 || true
  taskkill //F //IM workbench-daemon.exe >/dev/null 2>&1 || true
  schtasks //Change //TN "$TASK_NAME" //DISABLE >/dev/null 2>&1 || true
  schtasks //Delete //TN "$TASK_NAME" //F >/dev/null 2>&1 || true
  if [ -n "$PREV_RUN_VALUE" ]; then
    reg add "$RUN_KEY" //v "$RUN_KEY_NAME" //t REG_SZ //d "$PREV_RUN_VALUE" //f >/dev/null 2>&1 || true
  else
    reg delete "$RUN_KEY" //v "$RUN_KEY_NAME" //f >/dev/null 2>&1 || true
  fi
  rm -rf "$WORKBENCH_HOME"
  echo "(cleanup 完成——机器应已无 workbench 安装残留)"
}
trap cleanup EXIT INT TERM

wait_healthz() { # 最多 Ns（默认 30）
  local deadline=$((SECONDS + ${1:-30}))
  until curl -sf --max-time 2 "$BASE/healthz" >/dev/null 2>&1; do
    if [ "$SECONDS" -ge "$deadline" ]; then return 1; fi
    sleep 0.5
  done
}

# ---- S1: 静默首装 ----
echo "=== S1: setup /VERYSILENT 静默首装 ==="
"$SETUP_EXE" /VERYSILENT /SUPPRESSMSGBOXES /LOG="$WORKBENCH_HOME/innosetup-s1.log"
[ -f "$INSTALL_DIR/workbench.exe" ] && [ -f "$INSTALL_DIR/workbench-daemon.exe" ] && [ -f "$INSTALL_DIR/workbench-tray.exe" ] \
  || { echo "FAIL: S1 三制品未落盘"; exit 1; }
schtasks //Query //TN "$TASK_NAME" >/dev/null 2>&1 || { echo "FAIL: S1 计划任务未注册"; exit 1; }
[ -f "$START_MENU_LNK" ] || { echo "FAIL: S1 开始菜单快捷方式缺失"; exit 1; }
wait_healthz || { echo "FAIL: S1 服务 30s 内未就绪（ssPostInstall 未恢复？）"; exit 1; }
tasklist //FI "IMAGENAME eq workbench-tray.exe" 2>/dev/null | grep -i workbench-tray >/dev/null \
  || { echo "FAIL: S1 托盘进程未起"; exit 1; }
grep -i "error\|exception" "$WORKBENCH_HOME/innosetup-s1.log" >/dev/null && { echo "FAIL: S1 Inno 日志含 error"; exit 1; }
# 任务存在即禁用：daemon 触发无环境继承会用真实 profile 抢端口，干扰后续场景
schtasks //Change //TN "$TASK_NAME" //DISABLE >/dev/null
echo "PASS S1 静默首装（三制品 + 任务 + 快捷方式 + healthz + 托盘 + 日志无 error）"

# S2/S3/S4 由后续任务补
echo ""
echo "=== （S2/S3/S4 待后续任务落地） ==="
```

```iss
[Icons]
; 裁决 5+单实例唤醒语义：点快捷方式 = 托盘已跑则打开工作台页，没跑则拉起（启动即活）
Name: "{autoprograms}\数字员工工作台"; Filename: "{app}\workbench-tray.exe"; \
  WorkingDir: "{app}"; Comment: "数字员工工作台（托盘 + 本地服务）"

[Run]
; 裁决 3：复选框仅控制「打开工作台页面」；服务恢复已与用户解耦（ssPostInstall）。
; 经托盘 exe 而非 URL：托盘 openWorkbench 自带 healthz 等待 + 单实例唤醒语义，覆盖
; 「服务刚起未就绪」与「已就绪」两种时序。静默模式下 postinstall 跳过（Inno 原生，
; 无人值守不开浏览器——执行期设计修订，见计划头部）
Filename: "{app}\workbench-tray.exe"; Description: "打开工作台页面"; \
  Flags: postinstall nowait skipifsilent unchecked; Check: WizardNotSilent

[Code]
function InitializeSetup(): Boolean;
begin
  Result := True;
end;

// 装前清理（install.ps1 重装健壮性段翻译）：优雅停服务（释放 19980）→ 杀托盘（解文件锁）
procedure PrepareToInstall(var NeedsRestart: Boolean);
var
  ResultCode: Integer;
begin
  Exec(ExpandConstant('{app}\workbench.exe'), 'stop', '', SW_HIDE, ewWaitUntilTerminated, ResultCode);
  // stop 失败不中止（可能服务本就没跑）；兜底硬杀解文件锁
  Exec('taskkill', '/F /IM workbench-tray.exe', '', SW_HIDE, ewWaitUntilTerminated, ResultCode);
  Exec('taskkill', '/F /IM workbench.exe', '', SW_HIDE, ewWaitUntilTerminated, ResultCode);
  Exec('taskkill', '/F /IM workbench-daemon.exe', '', SW_HIDE, ewWaitUntilTerminated, ResultCode);
  Sleep(1500);
end;

// 系统集成 + 立即恢复（设计 §5.1 步骤 3/4；顺序：任务重建 → 清哨兵 → 起托盘）
procedure CurStepChanged(CurStep: TSetupStep);
var
  ResultCode: Integer;
begin
  if CurStep <> ssPostInstall then exit;
  // 计划任务 Force 重建（install.ps1:31-43 逐字翻译：四反直觉默认值覆写 + 每分钟触发器 365 天）
  // 单次 exec 合并（一次 PowerShell 启动注册完，压中断窗口）
  Exec('powershell.exe', '-NoProfile -Command "' +
    '$s = New-ScheduledTaskSettingsSet -AllowStartIfOnBatteries -DontStopIfGoingOnBatteries ' +
    '-ExecutionTimeLimit ([TimeSpan]::Zero) -MultipleInstances IgnoreNew -DontStopOnIdleEnd; ' +
    '$t = New-ScheduledTaskTrigger -Once -At (Get-Date).AddSeconds(30) ' +
    '-RepetitionInterval (New-TimeSpan -Minutes 1) -RepetitionDuration (New-TimeSpan -Days 365); ' +
    'Register-ScheduledTask -TaskName WorkbenchDaemon ' +
    '-Action (New-ScheduledTaskAction -Execute \"\"{app}\workbench-daemon.exe\"\" -Argument ''__daemon'') ' +
    '-Trigger $t -Settings $s -Force"', '', SW_HIDE, ewWaitUntilTerminated, ResultCode);
  // 安装意图 = 要运行：清 user-stopped 哨兵（install.ps1:47）
  Exec('cmd.exe', '/C del /q "%USERPROFILE%\.workbench\run\sentinels\user-stopped" 2>nul', '', SW_HIDE,
    ewNoWait, ResultCode);
  // 立即恢复（裁决 3：与用户解耦；托盘启动即活拉服务——服务幂等单实例判定）
  Exec(ExpandConstant('{app}\workbench-tray.exe'), '', ExpandConstant('{app}'), SW_HIDE, ewNoWait, ResultCode);
end;
```

```iss
// （接 Task 3 的 [Code] 段末尾追加）

// 数据目录解析：与制品 ProfileDir 语义一致（probe.go：WORKBENCH_HOME > ~/.workbench）
// 冒烟隔离安全性依赖此一致性——S4 删的是隔离目录而非真实 profile
function DataDir(): String;
var
  Home: String;
begin
  Home := GetEnv('WORKBENCH_HOME');
  if Home <> '' then begin
    Result := Home;
  end else begin
    Result := ExpandConstant('{%USERPROFILE|{sd}\Users\Public}') + '\.workbench';
  end;
end;

var
  DeleteData: Boolean;

procedure InitializeUninstall();
var
  i: Integer;
begin
  DeleteData := False;
  // 显式清除通道（裁决 2）：命令行 /DELETEDATA=1
  for i := 0 to ParamCount() - 1 do
    if CompareText(ParamStr(i), '/DELETEDATA=1') = 0 then DeleteData := True;
end;

procedure CurUninstallStepChanged(CurUninstallStep: TUninstallStep);
var
  ResultCode: Integer;
begin
  if CurUninstallStep = usUninstall then begin
    // 前置清理：优雅停（落哨兵，守护不复活）→ 杀壳 → 删任务 → 删 Run 键（W-16 双侧注销对齐）
    Exec(ExpandConstant('{app}\workbench.exe'), 'stop', '', SW_HIDE, ewWaitUntilTerminated, ResultCode);
    Exec('taskkill', '/F /IM workbench-tray.exe', '', SW_HIDE, ewWaitUntilTerminated, ResultCode);
    Exec('schtasks', '/Change /TN WorkbenchDaemon /DISABLE', '', SW_HIDE, ewWaitUntilTerminated, ResultCode);
    Exec('schtasks', '/Delete /TN WorkbenchDaemon /F', '', SW_HIDE, ewWaitUntilTerminated, ResultCode);
    Exec('reg', 'delete "HKCU\Software\Microsoft\Windows\CurrentVersion\Run" /v WorkbenchTray /f', '',
      SW_HIDE, ewWaitUntilTerminated, ResultCode);
    // 数据询问（裁决 2）：交互模式 MsgBox 默认否；静默零弹窗走默认保留
    if not UninstallSilent() then
      if MsgBox('是否同时删除用户数据（登录态 / 密钥 / 工程记忆）？' + #13#10 +
        '选择「否」可在重装后恢复全部状态（默认保留）。',
        mbConfirmation, MB_YESNO or MB_DEFBUTTON2) = IDYES then
        DeleteData := True;
  end;
  if CurUninstallStep = usPostUninstall then begin
    if DeleteData then
      DelTree(DataDir(), True, True, True);
  end;
end;
```
