## 1. 用户确认的设计

- 方案 2：Keycloak 是人员身份、凭据、任意深度 Group 树和 Membership 的唯一事实来源。
- 管理平台通过 Keycloak Admin API 管理组织和人员，PostgreSQL 保存组织/人员快照及业务权限。
- 每人一个主组织、零到多个协作组织。
- 权限点由系统定义，管理员可组合自定义角色。
- 角色可授予人员或组织；“授权对象包含下级成员”和“资源范围包含下级”是两个独立开关。
- 权限只做 allow 并集，第一期没有显式 deny。
- 委派者不能授予自己没有、不可委派或超出自身组织范围的权限。
